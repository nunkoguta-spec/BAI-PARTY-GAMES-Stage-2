# Clothing Match Fix — 2026-11-18

## Problem
The previous 50 added tops and 50 added bottoms were generated by resizing layers from a different 40x46 character rig. They could look too small/misaligned when layered over the game's 32x32 avatar.

## Fix
- Rebuilt the extra clothing directly for the project's 32x32 avatar rig.
- Tops remain **79 choices** total.
- Bottoms remain **64 choices** total.
- New clothing is painted per animation state and direction using the actual character silhouette as a clipping mask.
- Existing original clothing rows are preserved.
- Added distinct pixel-art styles: tees, stripes, polos, hoodies, jackets, varsity, sweaters, vests, button shirts, sports tops, jeans, chinos, shorts, cargo, skirts, sports bottoms, wide-leg, rolled, panel and utility styles.
- `tools/make-clothing-sheets.py` now points to the matching 32x32 generator so the old mismatched 40x46 workflow is not reused accidentally.

## Validation
- Tops sheets: 79 rows × 32px.
- Bottoms sheets: 64 rows × 32px.
- JavaScript syntax checks pass for the main modified JS files.
- Vite production build was attempted, but this environment currently reports `vite: not found`; no build-pass claim is made.
