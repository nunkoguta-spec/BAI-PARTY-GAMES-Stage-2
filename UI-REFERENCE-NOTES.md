# BAI PARTY GAMES — UI reference pass (2026-11-10)

## Changed
- New pixel-art UI atlas (`public/assets/ui/*`, generated by `tools/make-ui-assets.py`): gold-bordered navy/parchment 9-slice panels, title ribbon, green/gold/cream/red buttons, thumbnail frames, 6 category icons.
- `src/reference-ui.css` (menu + TV HUD) and `client-play/reference-ui.css` (HP customizer, header, quiz) load after the old styles; old features and DOM ids are unchanged.
- Menu: gold "BAI" logotype, ornate panel, coloured PLAY / CUSTOMIZATION / LEADERBOARD / SETTINGS / QUIT buttons.
- HP customizer: ribbon title, vertical category rail with icons, stage with pedestal, 4-column selectable grid with check badge, SIMPAN button (selections were already auto-saved; the button only confirms).
- HP quiz: pink timer bar, parchment question card, 2x2 answer buttons (correct = green, wrong = red).
- TV: stage badge (follows the stage the camera is in) and live leaderboard with P1-P4 chips (DOM overlay driven by the existing player list).

## Not done / not verified
- Not pixel-identical to the reference illustration. Chibi hero art, ICE train, dragon, podium scene and ornate icons are NOT recreated.
- No Hat / Accessory / Effect sprite layers exist, so those customizer categories are not shown.
- Press Start 2P loads from Google Fonts; offline it falls back to monospace.
- TV HUD and quiz panel were not screenshot-tested; menu and HP customizer were (Chromium, 1280x720 and 844x390).
- Jump/gravity, sync and Android/iOS fixes from the master prompt are still pending.

## Update: menu uses the supplied reference art
- `public/assets/ref/menu-banner.png` and `journey-strip.png` are crops of the user's reference image, used directly on the main menu. Buttons stay live HTML.
- `customize-panel.png`, `tv-mode.png`, `hp-mode.png` are also cropped and stored as visual targets, but are NOT wired into the game: costume thumbnails and characters in them do not correspond to this project's avatar layers.
- In-game characters and city backdrops are still the project's own assets, not the reference illustration.
- The tiny watermark text at the top-left of the banner comes from the source image.

## Update: menu fit fix
- Fixed the "Mulai Bermain" sub-panel being squashed (flex-shrink) so BUAT ROOM / GABUNG ROOM / KEMBALI were clipped with an inner scrollbar.
- Menu banner, panel and journey strip now scale to the viewport height; when a sub-panel is open the main button row is hidden (uses CSS :has, Chrome/Edge/Safari 15.4+/Firefox 121+).
- Checked in Chromium at 1251x717 and 844x390 (home, play-mode, join form). Real Android/iOS devices not tested.

## Update: gameplay uses the supplied asset pack
- `tools/extract-pack.py <collage.png>` cuts transparent sprites from the user's 1024x572 asset-pack collage into `public/assets/pack/` (mascot idle/run/jump/victory/hit, Rathaus tower, house facade + roof, lamp, market stall, tree, bush, ICE train, cobblestone).
- WorldScene: every player (local and remote) is drawn as the mascot, pose chosen from the existing animation state (idle / run / jump+fall / hit / interact). The old layered avatar is hidden but its code and costume data are untouched.
- München street now has houses, the Rathaus tower, lamps, stalls, trees, bushes and cobblestone; props and a parked ICE train repeat across all four chapters. Frankfurt/Berlin/Hamburg keep their own backdrops behind these props.
- Remote players get coloured "P1/P2..." labels (numbered by join order on that client).
- TV: host dashboard auto-collapses when the game starts (minibar moved bottom-left), duplicate in-canvas leaderboard/stage text hidden in favour of the DOM HUD, camera frames the street lower.
- HP landscape: compact header.

## Limitations
- Source collage is low-res and AI-style: each pose is ONE frame (run = bob + tilt), edges are slightly soft, and the 8 "customization avatars" and costume variants were NOT wired in (they are single poses, not layers).
- Customizer preview still shows the old layered avatar, not the mascot.
- Hamburg dragon / podium / Frankfurt-Berlin-Hamburg street tiles from the pack were not built into levels.
- Checked visually in Chromium (host 1366x720 + phone 844x390) with 2 simulated players; no real device test.
