HAMBURG ASSET PACK
==================

Pixel-art Hamburg harbor game asset pack.

This ZIP contains:
- hamburg_asset_pack_reference.png : original full asset-sheet reference
- 12 categorized folders for organizing/extracting individual sprites
- source_reference.png in each category as a source reference

The current source is a composite asset sheet. Individual sprites can be
cropped/exported into PNG files from these category folders in a next pass.
